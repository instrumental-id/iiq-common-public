= IIQ Common Public Repository
:toc:

== Introduction

IIQCommon is a utility library used in virtually all of our SailPoint IdentityIQ installations and plugins. This is the ever-expanding open source portion of this library, published under the Apache License 2.0. Feel free to create an account https://git.identityworksllc.com/pub/iiqcommon[on our Gitlab] to report issues or submit pull requests.

This repository is also https://github.com/instrumental-id/iiq-common-public[mirrored to Github.com].

https://instrumentalidentity.com/javadoc/iiq-common-public/index.html[Library Javadocs may be accessed at any time on Instrumental ID's site.]

== Maven repository

Updates to the `main` branch in this repository are pushed to our hosted GitLab's Maven package repository. You can set up this repository in your `pom.xml` using the following configuration:

[source,xml]
----
<repositories>
  <repository>
    <id>gitlab-maven</id>
    <url>https://git.identityworksllc.com/api/v4/projects/157/packages/maven</url>
  </repository>
</repositories>

<distributionManagement>
  <repository>
    <id>gitlab-maven</id>
    <url>https://git.identityworksllc.com/api/v4/projects/157/packages/maven</url>
  </repository>

  <snapshotRepository>
    <id>gitlab-maven</id>
    <url>https://git.identityworksllc.com/api/v4/projects/157/packages/maven</url>
  </snapshotRepository>
</distributionManagement>
----

Or Gradle repository configuration:

[source,groovy]
----
maven {
  url 'https://git.identityworksllc.com/api/v4/projects/157/packages/maven'
}
----

The Maven coordinates for the library are:

* Group ID: `com.identityworksllc.iiq.common.minimal`
* Artifact ID: `iiq-common-public`
* Version: A non-semver date string in the format `yyyyMM.dd.HHmmss` (e.g., `202310.03.170641`)

== Releases

Certain releases will be forked into branches. These will receive backports of significant bug fixes, but are not expected to receive major new functionality. Furthermore, these releases are intended to be stable against a target JDK and a target IIQ version. 

* `release/2024.10.07`: Stable with JDK 8 and IIQ 8.1 through 8.4.

== Building the library

=== JDK version

You must build this library with JDK 21 or later. This is the minimum version supported by the Markdown Javadoc doclet library.

Beginning with August 2026 releases, the library will be built with JDK 21 and will require JDK 17 or later to run. Older versions will still be usable by those running IIQ on old Java versions.

=== Supplying the IIQ dependencies

IDW cannot distribute SailPoint's proprietary IIQ binaries, so you must supply them yourself.

Insert the following JAR files from your IIQ version in the `lib/sailpoint` folder. (These files can be found in any IIQ WAR file at `WEB-INF/lib`.)

* identityiq.jar
* connector-bundle-identityiq.jar

=== IIQ 8.x and IIQ 9.x

IIQ 9.0 moved from the `javax` servlet, JAX-RS and JSF APIs to their `jakarta` replacements. A single JAR can't work on both sides of that change, so the library is built in two variants:

* The standard variant, for IIQ 8.x
* The `jakarta` variant, for IIQ 9.0 and later

The build decides which variants to produce from the IIQ JARs you supply:

[cols="1,1"]
|===
|IIQ JARs supplied |Variants built

|IIQ 8.x in `lib/sailpoint`
|Standard only

|IIQ 8.x in `lib/sailpoint`, plus IIQ 9.x in `lib-9.0/sailpoint`
|Standard and `jakarta`

|IIQ 9.x in `lib/sailpoint`
|`jakarta` only
|===

If you only run IIQ 9.0 or later, put your IIQ 9.x JARs in `lib/sailpoint`. The build will detect the version and produce only the `jakarta` variant. In that case:

* The unit tests are skipped, since they are written against the standard variant.
* The Javadocs are not generated. Use the link:https://instrumentalidentity.com/javadoc/iiq-common-public/index.html[published Javadocs] instead.
* Publishing tasks such as `publishToMavenLocal` will fail, because the Maven publication is built around the standard JAR. To publish, supply IIQ 8.x JARs in `lib/sailpoint` and IIQ 9.x JARs in `lib-9.0/sailpoint`.

To keep your IIQ 9.x JARs somewhere other than `lib-9.0/sailpoint`, pass their folder with `-Pidw.jakarta.iiqpath=<folder>`.

For how the `jakarta` variant is generated and compiled, and what to watch for when changing the code, see link:doc/IIQ-9.0.adoc[IIQ 9.0 and the jakarta variant].

=== Library JAR build

To build the library, execute `./gradlew build`. (On Windows, use `gradlew.bat build` instead.)

The library will be assembled in `build/libs`:

* `iiq-common-public-<version>.jar` is the standard variant, for IIQ 8.x.
* `iiq-common-public-<version>-jakarta.jar` is the `jakarta` variant, for IIQ 9.0 and later. The standard variant will not work on IIQ 9.0.

For deployment into your environment, you may want to manually remove the version tag so that you can always update the file in place.

IMPORTANT: In the future (perhaps 2028), this will be switched. The standard variant with no suffix will target IIQ 9.x and higher, while a separate `legacy` variant will be published for older installations.

=== Javadocs

You can assemble the Javadocs for this library using the `./gradlew javadoc` command. The Javadocs will be rendered using the link:https://github.com/mnlipp/jdrupes-mdoclet[mdoclet] library.

Files will be output to `build/docs/javadoc`.
